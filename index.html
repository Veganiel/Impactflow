WORKING IN THE PROTOTYPE

What you can inspect today

  • NEAR Intents supported-asset discovery and quote API integration.
  • Dry quote previews; preview mode does not create a deposit address.
  • A clearly labeled, no-payment contribution preview with an immediate receipt.
  • Local account, organization profile and project submission flows.
  • Verified on Testnet: campaign creation, reviewer approval, wallet-signed donations, milestone evidence and a reviewer-approved payout all completed on-chain. The deployed code hash matches this repository.
  • Post-goal staking contract state and reviewer-only pool configuration on Testnet.
STATUS, WITHOUT GUESSING

What is not claimed as complete

  • Milestone evidence is a submitted link: the contract enforces the review process, not the real-world truth of the evidence. The contract is not independently audited.
  • Optional staking and ongoing funds are deployed and migrated on Testnet (migrate_v2); no staking pool is configured yet, so the stake-to-withdraw cycle has not been live-tested.
  • Sample campaign totals and ledger entries are illustrative demo content.
  • Confidential Intents sign-in still needs a successful live wallet verification.
  • Organizations are unverified; this prototype is not production donation infrastructure.
60-SECOND WALKTHROUGH

Follow the actual product path

  1. Open Cross-chain and wait for supported assets to load.
  2. Select a source and destination asset; enter valid recipient and refund addresses.
  3. Request a dry quote preview and inspect the returned route.
  4. Open the escrow account on NEAR Explorer, then compare the manifest with the prototype limitations.

SECURITY & TRUST · IMPLEMENTED SAFEGUARDS

Designed to make the trust boundary visible.

Account protection

Salted password hashes, HttpOnly session cookies, origin checks and throttled sign-in attempts.

Implemented in server/index.js · checked by tests/api-smoke.test.js
No custody in the API

The backend does not hold user funds or send wallet transactions. Users review and sign transfers themselves.

NEAR Intents routes and Testnet escrow are separate flows.
Limits are explicit

Sessions and throttles are process-local. This prototype is not production infrastructure and has not had an independent security audit.
